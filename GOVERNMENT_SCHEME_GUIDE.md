# Government Scheme Automation - User Guide

## Overview
The Government Scheme Automation feature in Kisan Vaani provides farmers with a comprehensive solution for discovering, applying to, and tracking government schemes and benefits.

## Key Features

### 1. Voice to Form Filling
- **Voice Input**: Speak in Hindi, Marathi, or English to provide application details
- **Speech Recognition**: Converts voice to text automatically
- **Intent Parsing**: Understands your requirements (e.g., "Apply for PM Kisan")
- **Auto-Fill**: Extracts information like name, Aadhaar, mobile number, land size from voice input
- **Smart Mapping**: Automatically fills form fields with extracted data

#### Supported Voice Commands:
- "Apply for PM-KISAN scheme"
- "Check my application status"
- "Show fertilizer subsidy details"
- "My name is [Name], Aadhaar number is [12 digits]"
- "I have [X] acres of land"

### 2. Document Management
- **PDF Generation**: Auto-generates PDF documents for each application
- **Local Storage**: Saves all documents locally on your device
- **Smart Tagging**: Tags documents with scheme name and application date
- **Voice Search**: Find documents using voice commands
- **Easy Access**: View, share, or delete documents as needed

#### Voice Search Examples:
- "Show my Kisan Credit Card application"
- "Find PM-KISAN documents"
- "Show applications from last month"

### 3. Subsidy & Benefit Tracking
- **Real-time Status**: Check current status of all your applications
- **Benefit History**: Track all received subsidies and payments
- **Payment Details**: View transaction IDs and payment dates
- **Status Updates**: Get notifications when application status changes
- **Summary Dashboard**: See total received amounts and pending benefits

#### Tracked Information:
- Application status (Submitted, Under Review, Approved, etc.)
- Payment processing status
- Benefit amounts and dates
- Transaction IDs for successful payments

### 4. Policy Updates Feed
- **Latest Schemes**: Stay updated with new government schemes
- **Policy Changes**: Get notifications about policy modifications
- **Important Alerts**: Priority notifications for critical updates
- **Multilingual Content**: Updates in both English and Hindi
- **Source Links**: Direct links to official government websites

#### Notification Types:
- 🚨 Important policy changes
- 📢 New scheme launches
- ⏰ Application deadline reminders
- 💰 Subsidy payment notifications

## Available Government Schemes

### 1. PM-KISAN Samman Nidhi
- **Benefit**: ₹6,000 per year
- **Eligibility**: Small and marginal farmers with up to 2 hectares
- **Required Documents**: Aadhaar, Bank details, Land records

### 2. Kisan Credit Card (KCC)
- **Benefit**: Credit facility up to ₹3 lakhs
- **Eligibility**: Farmers with cultivable land
- **Required Documents**: Aadhaar, PAN, Land records, Income certificate

### 3. Crop Insurance (PMFBY)
- **Benefit**: Insurance coverage for crop losses
- **Premium**: 2% for Kharif, 1.5% for Rabi crops
- **Coverage**: Natural calamities, pests, diseases

### 4. Fertilizer Subsidy
- **Benefit**: Subsidized fertilizers
- **Eligibility**: All farmers
- **Process**: Available at authorized dealers

## How to Use

### Step 1: Access Government Schemes
1. Open Kisan Vaani app
2. Tap on "Govt Schemes" tab at the bottom
3. Browse available schemes or use voice search

### Step 2: Apply for a Scheme
1. Select a scheme from the list
2. Tap "Apply Now"
3. Use voice input or manual form filling
4. Review your information
5. Submit the application

### Step 3: Track Your Applications
1. Go to "My Applications" tab
2. View status of all submitted applications
3. Tap on any application for detailed tracking
4. Get notifications for status updates

### Step 4: Manage Documents
1. Navigate to "Documents" tab
2. View all generated PDF documents
3. Use voice search to find specific documents
4. Share or download documents as needed

### Step 5: Stay Updated
1. Check "Updates" tab for latest policy news
2. Enable notifications for important updates
3. Read detailed policy changes and new schemes

## Troubleshooting

### Common Issues:

1. **Voice not recognized**
   - Check microphone permissions
   - Speak in a quiet environment
   - Try speaking slower and clearer

2. **Form not auto-filling**
   - Ensure voice input contains required information
   - Manually fill remaining fields
   - Use standardized formats (e.g., 12-digit Aadhaar)

3. **Application status not updating**
   - Check internet connection
   - Tap refresh button
   - Manually update using tracking number

4. **Documents not generating**
   - Ensure storage permissions are granted
   - Check available storage space
   - Try submitting application again

### Support:
- Use in-app voice assistant for help
- Check FAQ section in the app
- Contact support through app settings
